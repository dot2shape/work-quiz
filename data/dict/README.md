# data/dict — 유행어 허용 목록·비속어 차단 목록

사용자 결정(2026-11-08, PRD #11): **유행어는 정답으로 인정하고, 비속어는 차단한다.**
이 폴더의 텍스트 파일이 두 목록의 원본이다. 관리자 화면은 없고, 파일을 고친 뒤 적재 스크립트로 D1(`word-rush-dict`)에 반영한다.

| 파일 | kind | 판정 | 단어 수(2026-11-15) |
|---|---|---|---|
| `slang.txt` | `slang` | 사전에 없어도 인정 | 395 |
| `banned.txt` | `banned` | 사전에 명사로 있어도 "사용할 수 없는 단어입니다"로 거절(쿨다운) | 179 |

두 파일 모두 외부 공개 목록을 복사하지 않고 아래 기준으로 직접 작성했다. 그래서 따로 표시할 라이선스가 없다.
외부 목록을 추가하려면 **라이선스를 원문으로 확인하고 출처·라이선스를 그 파일 머리 주석에 적는다. 라이선스가 불명확하면 쓰지 않는다.**

## 파일 형식

- 첫 줄 `# kind: slang` 또는 `# kind: banned` 는 **지시문**이다. 적재 스크립트가 이 줄로 종류를 정하므로 지우지 않는다. `--kind` 를 함께 주었는데 지시문과 다르면 적재가 멈춘다(차단 목록을 유행어로 넣는 사고 방지).
- 한 줄에 한 단어. 한글(가~힣) 2글자 이상, 띄어쓰기 없음. `#` 으로 시작하는 줄은 주석.
- 판정은 **제출한 단어와 완전히 같을 때만** 적용된다. `시발` 을 차단해도 `시발점` 은 차단되지 않는다. 그래서 표기 변형은 하나씩 적는다.

## 유행어(`slang.txt`) 인정 기준

넣는다:

- **명사로 쓰이는 말.** "○○이/가", "○○을/를" 로 자연스럽게 쓰인다(예: `갓생`, `워라밸`, `덕질`, `떡상`). 줄임말도 명사처럼 굳은 것은 넣는다(`갑분싸`, `내로남불`, `답정너`).
- 여러 해에 걸쳐 방송·기사·일상에서 널리 쓰여 뜻이 통하는 말.

넣지 않는다:

- **일시적 밈.** 한때 유행하고 사라지는 말투·유행 문구(예: 어쩔티비, 킹받네, 중꺾마).
- **문장형 줄임말.** 명사가 아니라 문장을 줄인 것(예: 할많하않, 안물안궁, 이생망, 낄끼빠빠, 복세편살).
- 감탄사·부사·형용사로만 쓰이는 말(예: 가즈아, 엄근진).
- 비속어에서 나온 말. 욕설 강조어 `존-`·`개-` 가 붙은 말(존맛, 존버, 개이득), 특정 집단을 낮추는 말(`-충`, 관종, 듣보잡, 헬창), 어린이를 미숙함에 빗댄 `-린이`(주린이, 헬린이)는 인정 목록에 넣지 않는다. 이 가운데 혐오·욕설에 해당하는 것만 차단 목록에 넣고, 나머지는 어느 목록에도 넣지 않는다(사전에 없으면 "사전에 없는 단어").
- 상표·서비스 이름, 사람 이름.

표준국어대사전에 이미 있는 단어가 섞여 있어도 해롭지 않다(어차피 인정).

## 비속어(`banned.txt`) 차단 기준

넣는다:

- **욕설**: 씨발·씹·좆·지랄·염병 계열, `개-`·`-놈`·`-년`·`-새끼` 욕, 부모를 욕하는 말. 자주 쓰는 표기 변형 포함.
- **성적 표현**: 성기·성행위를 가리키는 속어와 음란물을 가리키는 말(`야동`, `포르노`, `섹스` 포함). 의학·교육 용어(성교, 음경, 자위 등)는 넣지 않는다.
- **혐오 표현**: 성별·세대·종교·정치 성향·인종·국적·지역 집단을 낮추는 말(`맘충`, `틀딱`, `짱깨`, `쪽발이`, `전라디언` 등).
- **비하 표현**: 장애·지능을 빗대 사람을 낮추는 말(`병신`, `찐따`, `저능아` 등).

넣지 않는다:

- **일상어와 동형인 단어.** 일상 뜻이 주된 단어는 욕으로 쓰일 수 있어도 차단하지 않는다. 예: `개`, `새끼`(동물의 어린 것), `걸레`, `고자`, `등신`(等身), `대가리`(생선 대가리), `아가리`(병 아가리), `검둥이`(검은 개), `홍어`, `쓰레기`, `호구`, `애비`·`애미`(방언).
- 뜻이 순한 낮춤말(바보, 멍청이, 얼간이, 머저리)과 욕이 아닌 거친 말(개소리, 젠장).
- 사전에 중립적으로 실린 말(매춘부, 변태, 벙어리 등 속담·문학에 쓰이는 옛 표현 포함).

경계에 있어 판단을 적어 두는 단어:

| 단어 | 결정 | 이유 |
|---|---|---|
| `시발` | 차단 | 사전에 `시발(始發)` 이 있지만 단독으로는 욕설 변형으로 읽히는 경우가 주되다. `시발점`·`시발역` 은 차단되지 않는다 |
| `병신` | 차단 | 간지 `병신(丙申)` 과 동형이지만 주된 쓰임이 욕설·장애 비하다 |
| `보지`·`자지` | 차단 | 명사로는 성기 속어뿐이다(동사 활용형은 명사가 아니라 정답이 될 수 없다) |
| `섹스` | 차단 | 사전에 있는 외래어지만 "성적 표현 차단" 결정에 따라 넣었다 |
| `한남` | 차단 | 지명에서는 `한남동`·`한남대교` 처럼 쓰이고, 단독으로는 성별 혐오 표현으로 읽힌다 |
| `흑형` | 차단 | 호의로 쓰여도 인종을 지칭하는 차별 표현으로 지적된다 |
| `호로`·`후장`·`운지`·`애자` | 차단 안 함 | 일상어(호로병의 호로, 증시 후장, 운지버섯, 애자 절연체)와 동형 |

## 두 목록에 같은 단어가 있으면

**banned 가 우선한다.** 판정은 차단 목록을 가장 먼저 보고(`BlocklistDictionary`, `D1Dictionary`), 제시어 집계(`prompt_syllables`)도 차단 단어를 뺀다.
적재 스크립트는 한 번에 읽은 파일에서 겹치는 단어를 찾아 경고한다. 그래서 **두 파일은 항상 함께 적재한다.**

```
경고: slang 과 banned 에 모두 있는 단어 1개 — banned 우선(차단됩니다). 유행어 목록에서 지우세요: 갑질
```

`npm test`(`test/dict-lists.test.ts`)도 최소 개수(유행어 200·차단 100), 형식, 중복, 두 목록의 겹침, 일상어 동형 단어가 차단 목록에 없는지를 확인한다.

## 고치고 반영하는 법

```bash
# 1) 파일을 고친다 → 2) 검사
npm test
node scripts/dict/load.mjs data/dict/slang.txt data/dict/banned.txt --replace --dry-run   # 건수·경고만 확인

# 3) 로컬 D1 에 넣어 확인 (wrangler dev 용)
npx wrangler d1 migrations apply word-rush-dict --local
node scripts/dict/load.mjs data/dict/slang.txt data/dict/banned.txt --replace --local

# 4) 운영 D1 에 반영 (main 병합·배포 뒤)
node scripts/dict/load.mjs data/dict/slang.txt data/dict/banned.txt --replace --remote
```

- `--replace` 는 출처가 `slang.txt`·`banned.txt` 인 기존 행을 지우고 다시 넣는다. 파일에서 지운 단어가 DB 에서도 사라진다. 사전 명사(`standard`) 행은 건드리지 않는다.
- 적재 결과는 **새로 만들어지는 방부터** 적용된다(방이 만들어질 때 차단 목록을 한 번 읽는다).
- 반영 확인: `curl https://quiz.ooo.codes/healthz` 의 `d1.slang`·`d1.banned` 가 위 표의 단어 수와 같아야 한다(60초 캐시).
