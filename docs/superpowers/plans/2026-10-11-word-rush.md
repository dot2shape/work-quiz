# 첫글자 배틀 (Word Rush) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 제시어로 시작하는 명사를 가장 먼저 제출한 사람이 득점하는 2~8인 실시간 웹 게임을 FastAPI + WebSocket으로 구현하고 quiz.ooo.codes로 공개한다.

**Architecture:** 단일 FastAPI 프로세스가 방·라운드 상태 머신과 선착순 판정(Arbiter)을 메모리에서 관리한다. 사전 판정은 `Dictionary` 프로토콜 뒤에 표준국어대사전 API 클라이언트 + 캐시(키 없을 때 로컬 시드 사전)를 둔다. 클라이언트는 빌드 없는 `static/index.html` 한 장이다.

**Tech Stack:** Python 3.12+, FastAPI, uvicorn, httpx, pytest + pytest-asyncio, uv, pm2, cloudflared

**Spec:** `docs/superpowers/specs/2026-10-11-word-rush-design.md`

## Global Constraints

- API 키는 `STDICT_API_KEY` 환경변수로만 읽는다. 코드에 키 하드코딩 금지. `.env.example`만 커밋.
- 승자 결정은 서버 `seq` 순서. 클라이언트가 보낸 시각은 어떤 경우에도 사용하지 않는다.
- 방·점수는 메모리만. DB·외부 저장소 금지.
- UI 문구는 한국어. 코드 주석 한국어, 식별자 영문.
- 포트 5020, pm2 프로세스명 `word-rush`.

## Review Focus

1. 제시어 공개 직전(countdown)에 도착한 제출 → 거부되어야 하며 점수 반영 금지. (Task 4 테스트)
2. 앞 순번 제출의 API 검증이 느려 뒤 순번이 먼저 "유효"로 판정될 때 → 뒤 순번은 앞 순번 결과 전까지 보류. (Task 3 테스트)
3. 승자 확정 후 동시 도착한 유효 제출 → 두 번째 득점 금지. (Task 4 테스트)
4. 접속 끊긴 방장 → 다음 연결된 플레이어가 방장 승계, 게임은 계속. (Task 4 테스트)
5. 사전 API 오류 → 제출자에게만 `error` 사유, 라운드 지속, 캐시에 오류 저장 금지. (Task 2 테스트)

### Task 2: 사전 계층

**Files:** Create `app/dictionary.py`, `data/seed_words.txt`, `tests/test_dictionary.py`

**Interfaces (Produces):**
```python
@dataclass(frozen=True)
class Verdict: valid: bool; reason: str | None = None; error: bool = False
class Dictionary(Protocol):
    name: str
    async def is_noun(self, word: str) -> Verdict: ...
class StdictClient(Dictionary): def __init__(self, api_key: str, client: httpx.AsyncClient | None = None, timeout=3.0)
class CachedDictionary(Dictionary): def __init__(self, inner: Dictionary, path: Path | None, max_size=50_000); async def is_noun; def save()
class LocalDictionary(Dictionary): def __init__(self, words: set[str]); @classmethod from_file(path)
def build_dictionary(settings) -> Dictionary
```
- [ ] 테스트: StdictClient 파싱(httpx.MockTransport로 `{"channel":{"total":1,"item":[{"word":"부산","pos":"명사"}]}}` → valid; pos "동사"만 → invalid reason "명사가 아닙니다"; total 0 → invalid "사전에 없는 단어"; 500 → error=True)
- [ ] 테스트: CachedDictionary는 두 번째 호출에서 inner를 호출하지 않음; error 결과는 캐시하지 않음; save/load 왕복
- [ ] 테스트: LocalDictionary from_file
- [ ] 구현 → PASS → commit `feat: 표준국어대사전 클라이언트, 캐시, 로컬 사전`

### Task 3: Arbiter(선착순 판정기)

**Files:** Create `app/arbiter.py`, `tests/test_arbiter.py`

**Interfaces (Produces):**
```python
class Arbiter:
    def __init__(self, on_winner: Callable[[Submission], Awaitable[None]])
    def submit(self, player_id: str, word: str, check: Awaitable[Verdict]) -> Submission  # seq 부여, 태스크 시작
    def close(self)  # 남은 태스크 취소
@dataclass class Submission: seq:int; player_id:str; word:str; verdict: Verdict|None; future: asyncio.Future[Verdict]
```
- [ ] 테스트: 앞 순번(느린 검증, 결과 invalid) + 뒤 순번(빠른 검증, valid) → on_winner는 뒤 순번으로 **앞 순번 결과 이후**에만 호출
- [ ] 테스트: 앞 순번 valid, 뒤 순번 valid → 승자는 앞 순번, on_winner 1회
- [ ] 테스트: close() 후 늦게 끝난 검증은 on_winner 호출 없음
- [ ] 구현 → PASS → commit `feat: 선착순 판정기 Arbiter`

### Task 4: Room 상태 머신 + RoomManager

**Files:** Create `app/room.py`, `app/manager.py`, `tests/test_room.py`

**Interfaces (Produces):**
```python
@dataclass class Player: id:str; token:str; nickname:str; score:int=0; connected:bool=True; cooldown_until:float=0.0
class Room:
    def __init__(self, code, dictionary: Dictionary, settings, broadcast: Callable[[dict], Awaitable], send: Callable[[str, dict], Awaitable], picker=None, sleep=asyncio.sleep)
    phase: Literal["lobby","countdown","playing","round_end","game_over"]
    def add_player(nickname, token=None) -> Player  # 재접속 시 token으로 기존 Player 복구
    def disconnect(player_id); def is_empty() -> bool; def state() -> dict
    async def start(player_id)  # 방장만, 2명 이상
    async def submit(player_id, word)  # phase 검사 → 쿨다운 → 형식 → 중복 → Arbiter
    async def restart(player_id)
    def close()
class RoomManager: create(dictionary, settings, broadcast_factory...) ; get(code) ; sweep(now)
```
- [ ] 테스트(가짜 Dictionary, sleep 즉시 반환): 2인 시작 → countdown 중 제출 거부 → playing에서 유효 단어 득점 → used_words 포함 → 중복 거부 → 5점 game_over
- [ ] 테스트: 방장 disconnect → host_id 승계
- [ ] 테스트: 승자 확정 후 추가 유효 제출은 득점 없음
- [ ] 테스트: 라운드 타임아웃 → winner 없음 round_end
- [ ] 구현 → PASS → commit `feat: 방 상태 머신과 RoomManager`
